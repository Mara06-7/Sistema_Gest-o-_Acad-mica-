# Sistema_Gestao_Acadamica
Projeto de Gestão de Notas em C++

Neste repositório, apresento a evolução de um sistema de gestão académica.
A Versão 1 foca na lógica de arrays e menus. 
A Versão 2 implementa structs e persistência de dados em ficheiros.
A Versão 3 implementado todo o ciclo de um CRUD.
